2D Godot Del 7 - Exploding Player

Nu kan vi skyde vores enemies…men de kan ikke skyde igen, det er da lidt snyd så lad os få rettet op på det.

I denne lektion skal vi:

  • Have lavet nogle EnemyBullets.
  • Have vores fjender til at skyde de bullets efter os med tilfældige intervaller.
  • Sørge for at vi kan blive ramt af EnemyBullets.
  • Vores skib har et avanceret skjold så det kan holde til at blive ramt flere gange, men vi skal tælle vores health ned, og når den rammer 0 skal vi selv dø i en kæmpe eksplosion

Lad os komme igang, første del er nem.

EnemyBullet

Ganske som vores PlayerBullet skal vi nu have lavet en EnemyBullet, den skal bestå af:

  • En root node af typen Area2D
  • En CollisionShape2D
  • En Sprite2D (du kan finde billeder af projektiler i Projectiles mappen under assets)
  • En VisibleOnScreenNotifier
  • Et script

Ligesom vi gemte vores PlayerBullet i en mappe under Player, skal vi gøre det samme med EnemyBullet i en mappe under Enemy her.

Det skulle gerne se sådan her ud til sidst.

Og med det her script til at starte med

extends Area2D

@export var speed = 600.0

func _on_visible_on_screen_notifier_2d_screen_exited() -> void:
    queue_free()

Tilføjelser til Enemy

Nu er vi klar til at affyre kugler fra vores Enemy.

Men…da vores Enemy ikke bare kommer flyvende lige oppefra og ned kan vi ikke bare lægge til Y værdien, det ville se underligt ud at vores fjender kiggede mod højre og så bare fyrede lige nedad.

I stedet vil vi gerne skyde i den retning vores fjender kigger. Heldigvis er det forholdvist nemt i Godot, vi skal bruge lidt fysik men vi får det hele forærende.

Vi skal bruge:

  1. Et punkt vi kan skyde fra
  2. En timer der kan få os til at skyde efter at have et tilfældigt tidsrum
  3. Den retning vi kigger i når der skal skydes

Og det er det, så lad os starte med at tilføje et par ting til vores Enemys Area2D rod node.

Tilføj:

  1. En Marker2D node som vi kalder GunMuzzle.
  2. En Timer som vi kalder ShootTimer, sæt den til at være One Shot i Inspectoren, vi skal nok selv starte og stoppe den.

Sæt nu dit GunMuzzle point så det sidder lige foran spidsen af vores AnimatedSprite2D, det er her skuddene kommer fra

Så mangler vi bare lige to ting, inden vi kan komme til at skrive scriptet.

Først en reference til vores EnemyBullet fra en Enemy, ganske som vi havde mellem PlayerBullet og Player.

Tilføj den her linie i starten af Enemy scriptet under dine signals

@export var bullet: PackedScene

Og forbind Enemy med EnemyBullet ved at trække enemy_bullet.tscn ind på bullet i Inspectoren for Enemy.

Og så skal vi lige have hooket ShootTimerens timeout signal op mod Enemy scriptet ganske som vi plejer.

Og så er vi klar til scriptet

Enemy script tilføjelser

Vi skal have lavet tre ting.

  1. Fortalt vores ShootTimer at dens wait_time er et tilfældigt tal og startet timeren.
  2. Gøre “noget” når ShootTimeren fyrer.
  3. Stoppe ShootTimeren når vi er ramt så vi ikke bliver ved med at fyre kugler afsted.

Klargør timeren

To linier i _ready()

$ShootTimer.wait_time = randf_range(0.75, 1.5)
$ShootTimer.start()

Læg mærke til randf_range, den giver os et tilfældigt tal mellem 0,75 og 1,5, så vores fjender vil altså skyde efter os i et tidsrum mellem 0,75 sekunder og 1,5 sekund.

_ready ser nu sådan her ud:

func _ready() -> void:
    $Ship.play("default")
    $ShootTimer.wait_time = randf_range(0.75, 1.5)
    $ShootTimer.start()

Skyd

Vores funktion til når timeren fyrer ser sådan her ud

func _on_shoot_timer_timeout() -> void:
    var new_bullet = bullet.instantiate()
    get_tree().root.add_child(new_bullet)
    new_bullet.transform = $GunMuzzle.global_transform

    # Start over
    $ShootTimer.wait_time = randf_range(0.75, 1.5)
    $ShootTimer.start()

Første og anden linie kender vi, vi laver en ny bullet og vi putter den i view træet

Transform er nyt. Hvis du kigger på dem kan du se, at transform er af typen Transform2D og i dokumentationen står der:

The Transform2D built-in Variant type is a 2×3 matrix representing a transformation in 2D space. It contains three Vector2 values: x, y, and origin. Together, they can represent translation, rotation, scale, and skew.

OK, det blev vi måske ikke så meget klogere af. Hvad er en matrix?

En matrix er det samme som en tabel eller et array i andre programmeringssprog, altså rækker og kolonner.

Den her Transform2D indeholder så 3 Vector2 værdier, det er bare X og Y koordinater.
Så vi får altså at vide:

  • Origin: I hvilket X, Y koordinat er vi startet?
  • X: Hvilken X retning flyver vi i
  • Y: Hvilken Y retning flyver vi i

Og alt det her kan vi så bruge til at sige:

New_bullet skal bevæge sig i samme retning som vores GunMuzzle gør lige nu.

Derefter gør vi lige timeren klar og starter den igen så vi kan nå at skyde igen.

Stop med at skyd når vi er døde

Sidste ting. Vi skal ikke skyde mere efter at vi er ramt, så vi stopper lige timeren i hit funktionen så den nu ser sådan her ud:

func hit() -> void:
    enemy_hit.emit()
    $ShootTimer.stop()
    $Ship.play("explosion")
    await $Ship.animation_finished
    died.emit(5)

Det var det i Enemy, nu har vi sat en kugle som peger i samme retning som vores Enemy, men vi skal også lige have den til at flyve så vi skal et smut tilbage i EnemyBullet scriptet.

EnemyBullet script tilføjelser

Det nye er at vi skal bruge Y værdien fra transform som vi satte ovre i vores Enemy.

Hvad skal der ske her?

Vi skal tælle en shield værdi ned, og hvis den rammer 0, så skal vi dø og springe i luften.

Lad os starte med at lave en shield og en max_shield variabel i toppen af vores Player script:

var max_shield = 3
var shield = 3

Og så lad os sætte dem op i start sådan at man altid starter med max shield

shield = max_shield

Nu kan vi så trække en fra shield i vores hit funktion, og hvis vores shield <= 0, så er vi døde!

func hit() -> void:
    shield -= 1
    if shield <= 0:
        die()

func die() -> void:
    print("dead")

Prøv at kør dit spil nu og så lad dig blive ramt 3 gange, nu skulle du gerne se “dead” printet ud i konsollen i bunden af Godot

Helt død!

Godt, men hvad skal der så ske i die funktionen?

Vi vil gerne lige sætte en boolean is_dead til true så vi ikke bliver ramt igen og så vi ikke kan bevæge os f.eks.

Tilføj is_dead som endnu en variabel i toppen

var is_dead = false

Og sæt den til false når vi kalder start(), bare for at nulstille alt når vi starter et nyt spil.

is_dead = false
Nu kan vi lige kigge om is_dead = true inden vi begynder at afgøre hvor spilleren skal flytte sig hen og så videre i _process for det er der jo ingen grund til.

func _process(delta: float) -> void:
    if is_dead:
        return
    …

Og endelig skal vi jo så også lige sætte is_dead til true i die:

func die() -> void:
    is_dead = true

Næste skridt er at afspille en animation, ganske som vi gjorde med vores enemies.

Lav en ny animation ud fra SpriteFrames på dit Ship, ganske som du gjorde med Enemy, du kan finde eksplosions sprite sheets i Explosions mappen under assets.

Og så skal vi spille den animation i vores die funktion og fjerne os selv fra køen som det sidste.

func die() -> void:

    $Ship.play("explode")
    await $Ship.animation_finished

Kør nu dit spil og bliv ramt 3 gange….booom


Men hov! Vores booster animation kører lystigt videre selvom vi eksploderer i et flammehav, lad os lige gemme den med:

$Boosters.hide()

I vores die funktion, og sørge for at vise dem igen i start med

$Boosters.show()

Prøv så at kør igen. Bedre.

Sidste detaljer

Lad os lige emite et signal om at vores Player er død sådan at vi i vores Game kan reagere på det og vise game over skærm og så videre.

Tilføj to nyt signaler i toppen af Player scriptet

signal player_died
signal shield_changed(max_shield: int, shield: int)

Det ene kan vi bruge når vi er døde og det andet bruger vi hver gang vi er ramt til at opdatere en health bar i UI. Bemærk at vi kan tilføje parametre til vores signals.

Emit player_died fra vores die funktion

func die() -> void:
    is_dead = true
    $Boosters.hide()
    $Ship.play("explode")
    await $Ship.animation_finished
    player_died.emit()
    queue_free()

Og emit shield_changed fra hit funktionen efter at vi har talt shield ned:

func hit() -> void:
    shield -= 1
    shield_changed.emit(max_shield, shield)
    if shield <= 0:
        die()

Læg mærke til at vi sender to værdier med her, max_shield og shield. Dem kan vi bruge til at tegne en fin health bar med senere.

Komplet Player Script

For en god ordens skyld får du lige hele Player scriptet her, det er ved at være lidt langt.

extends Area2D

# Signals

signal player_died
signal shield_changed

@onready var screen_size = get_viewport_rect().size
@export var speed = 400.0
@export var player_bullet: PackedScene
@export var gun_cooldown = 0.25

var max_shield = 3
var shield = 3
var can_shoot = true
var is_dead = false
var current_animation = ""

func start():
    can_shoot = true
    is_dead = false
    $GunCooldownTimer.wait_time = gun_cooldown
    position = Vector2(screen_size.x / 2, screen_size.y - 64)

    shield = max_shield
    $Boosters.show()
    $Boosters.play("default")

# Called when the node enters the scene tree for the first time.

func _ready() -> void:
    pass # Replace with function body.

# Called every frame. 'delta' is the elapsed time since the previous frame.

func _process(delta: float) -> void:
    if is_dead:
        return

    # Movement
    var input = Input.get_vector("left", "right", "up", "down")
    position += input * speed * delta
    position = position.clamp(Vector2(24, 24), screen_size - Vector2(24, 24))

    # Animations
    var next_animation = "forward"
    if input.x < 0:
        next_animation = "left"
    elif input.x > 0:
        next_animation = "right"

    if next_animation != current_animation:
        current_animation = next_animation
        $Ship.play(current_animation)

    if Input.is_action_pressed("fire"):
        shoot()

func shoot():
    if not can_shoot:
        # Nope...too soon
        return

    # Flip the flag
    can_shoot = false

    # Start the timer
    $GunCooldownTimer.start()

    # Shoot
    var bullet = player_bullet.instantiate()
    get_tree().root.add_child(bullet)
    bullet.start(position + Vector2(0, -32))

func hit() -> void:
    shield -= 1
    shield_changed.emit(max_shield, shield)
    if shield <= 0:
        die()

func die() -> void:
    is_dead = true
    $Boosters.hide()
    $Ship.play("explode")
    await $Ship.animation_finished
    player_died.emit()
    queue_free()


func _on_gun_cooldown_timer_timeout() -> void:
    can_shoot = true
